# 🤝 Integração com Lovable

Este documento detalha como a plataforma Lovable é integrada ao fluxo de desenvolvimento e design do Bloodmage 1995.

## ⚙️ Diretrizes de Integração
- **Geração de Telas**: Lovable auxilia na prototipagem e desenvolvimento de componentes interativos em React, permitindo que alterações cosméticas de HUD e overlays sejam exportadas diretamente.
- **Sincronização de Chaves**: A persistência de dados exportados usa as chaves padronizadas (`bloodmage_1995_settings`, `bloodmage_1995_highscores`) validadas com os esquemas estritos do Zod.
- **Id de Projeto Stitch**: O identificador de projeto para o design de telas do Bloodmage 1995 é `15904943689111382828`.
