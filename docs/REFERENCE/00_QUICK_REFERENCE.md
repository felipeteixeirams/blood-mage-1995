# 🧭 Guia de Referência Rápida

Este é um sumário de consulta rápida para comandos e chaves de persistência comuns em Bloodmage 1995.

## ⚡ Comandos Rápidos

| Tarefa | Comando |
| :--- | :--- |
| **Iniciar Servidor Dev** | `pnpm run dev` |
| **Verificar Tipagem** | `pnpm run typecheck` |
| **Executar Build Completa** | `pnpm run build` |
| **Rodar Testes Unitários** | `pnpm test` |
| **Pipeline de Validação** | `pnpm run verify` |

## 🔑 Chaves de Persistência (localStorage)
- Configurações do Jogo: `bloodmage_1995_settings`
- Tabela de High Scores: `bloodmage_1995_highscores`
- Cristais de Sangue: `bloodmage_1995_blood_crystals`
- Níveis de Talentos: `bloodmage_1995_talents`
