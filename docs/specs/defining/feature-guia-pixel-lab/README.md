# Guia para Pixel Lab — índice

**Contexto:** spec em pasta, dividida em partes; cada parte tem o cabeçalho de spec. Estágio e aprovação valem para todas. É um guia de prompts de ferramenta externa: os critérios EARS (IDs `PL-`, parte 6) descrevem as entregas de arte, não o texto dos prompts.
**Leia quando:** for ler, aprovar ou produzir a arte descrita; comece pela parte 01 e termine na 06.

| Parte | Papel |
|---|---|
| [01-config-e-jogador.md](01-config-e-jogador.md) | Contexto, decisões, fatos, escopo, contratos de entrega e configuração global com os prompts do jogador |
| [02-bestiario-1.md](02-bestiario-1.md) | Prompts dos inimigos 1 a 6 |
| [03-bestiario-2.md](03-bestiario-2.md) | Prompts dos inimigos 7 a 11 |
| [04-npcs-e-props.md](04-npcs-e-props.md) | Prompts dos NPCs do refúgio e props de cenário |
| [05-tiles-e-tabela.md](05-tiles-e-tabela.md) | Prompts dos tiles e tabela resumo |
| [06-criterios-e-pendencias.md](06-criterios-e-pendencias.md) | Critérios de aceite, plano de verificação, questões em aberto, pendências e referências |
