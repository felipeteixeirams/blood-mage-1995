# 👁️ Identidade Visual e Paleta de Cores

Bloodmage 1995 utiliza uma paleta de cores restrita inspirada no horror gótico dos anos 90, preservando forte impacto de contraste.

## 🎨 Paleta de Cores "Grimdark"

| Cor | Nome | Hex | Aplicação |
| :--- | :--- | :---: | :--- |
| **Deep Charcoal** | Fundo Principal | `#171309` | Painéis, fundos de menu, modais |
| **Crimson Blood Red** | Vermelho Sangue | `#990000` | Barra de Vida, feitiços de hemomancia, partículas |
| **Tarnished Gold** | Ouro Envelhecido | `#B8860B` | Bordas douradas, destaques, botões ativos, talentos |
| **Bone White** | Branco Osso | `#E3DAC9` | Tipografia principal, Courier text |
| **Abyssal Void** | Preto Profundo | `#000000` | Sombra projetada, nevoeiro inexplorado |
